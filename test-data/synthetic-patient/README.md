# Synthetic second patient

These documents were written for this project to test behaviour the supplied record cannot:
a second patient, a treatment-plan change, a service the first plan does not mention, a contact
with no visit identifier, and a duplicate file that differs only in line endings.

They are fictional. They use a different layout, different labels and a different identifier
scheme from the supplied documents on purpose. They are not part of the submitted abstraction
of the supplied record.
