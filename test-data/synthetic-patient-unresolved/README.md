# Synthetic patient with an unresolved week

These documents were written for this project to test one case the brief names and no other
document set produces: a patient whose inclusion in the list of "two consecutive weeks below the
requirements" depends on unresolved documentation.

The patient has one week that is clearly below the goal, followed by a week whose total depends
on two signed notes that give different start times for the same session.

They are fictional, and use a layout and identifier scheme of their own.
